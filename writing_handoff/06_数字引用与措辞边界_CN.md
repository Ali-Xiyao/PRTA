# 数字引用与措辞边界

## 可以直接使用

- “supports the importance of finding-conditioned querying”
- “is consistent with the intended temporal mechanism”
- “achieved competitive performance on the frozen development cohort”
- “demonstrated sensitivity to controlled PRIOR perturbations”
- “cross-fitted temperature scaling modestly reduced ECE”
- “cross-source performance was directionally asymmetric”

## 禁止或必须改写

| 不可使用 | 建议改写 |
| --- | --- |
| significantly outperformed all baselines | performed competitively; paired intervals overlapped zero |
| official BioViL-T/CheXRelNet implementation | architecture-inspired internal reimplementation |
| external clinical validation | bidirectional source-held cross-source evaluation |
| clinically causal use of PRIOR | behavioral sensitivity under controlled PRIOR intervention |
| clinically calibrated / safe to deploy | calibration characterized on the frozen Dev cohort |
| end-to-end latency | cached-feature model-forward latency |
| clinical referral benefit | offline selective-prediction/referral simulation |
| robust to missing history | performance under a synthetic null-PRIOR intervention |

## 投稿前数字核对

- 所有主表均报告 mean ± sample SD，不报告 best seed。
- Δ 的方向必须在表注中定义。
- ODER 标明越低越好。
- CI 使用方括号并保留正负号。
- outcome-ranked CheXRelNet 对比必须标“exploratory”。
- 所有 p 值区分 empirical、Holm-adjusted 和 exploratory。
