# 方法与贡献写作卡

## 任务定义

输入为同一患者的 current CXR 表示、PRIOR CXR 表示和目标 finding 文本，输出五类纵向进展状态：Stable、Improved、Worse、New、Resolved。Official Dev 含 11,201 条观察、2,427 名患者；统计推断以患者为聚类单位。

## 最终方法信息流

1. **Finding-conditioned visual query**：finding 文本生成查询条件，使视觉路径关注与目标病灶相关的证据。
2. **Cross-time alignment**：使用跨时间注意力将 PRIOR token 对齐到 current 查询，避免比较未对齐视觉表示。
3. **Temporal relation residual**：显式构造 prior-current relation，并以 residual 注入 transition representation。
4. **Progression prediction**：融合 current、aligned PRIOR、relation 与 finding 条件后预测五类状态。

State tokens 只服务训练期 state-anchor；冻结 H0 推理头只消费 transition tokens。
Temporal relation residual 直接以 `current + relation residual` 注入，最终配置没有
启用 learned/fixed residual scale。

## 最终激活的训练目标

| 目标 | 权重 | 论文角色 |
| --- | ---: | --- |
| Classification | 1.0 | 主五分类目标 |
| State anchor | 0.025 | 状态保持约束 |
| Opposite-direction cost | 0.05 | 抑制 Improved/Worse、New/Resolved 等方向性错误 |
| Matched-hard CMCP | 0.01 | 强化患者历史特异性 |

Standalone Prototype CE、DMW 以及其余冻结权重恒为 0 的历史损失不属于最终方法，不能再画进最终损失函数图。

## 冻结配置

- 对外方法名：PRTA-CXR。
- 配置身份：Slim-S1。
- Adapter scope：Tail8；不要误写为“只取最后 8 个 token”。
- Native head：H0。
- Seeds：17、28、43。
- Optimizer、EMA、early stopping、batch、learning rate 等以 `configs/final/prta_cxr_slim_s1.json` 为准。

## 建议贡献点

1. Finding-conditioned、relation-aware 的纵向 CXR 融合框架。
2. 同 backbone、同预算、固定三 Seed 的精确结构消融与通用融合对照。
3. 受控 PRIOR 审计的协议与完成边界；最终公开包不提供 S1 定量表，也不把历史 V2
   四条件表改名为最终结果。
4. 10,000 次 patient-cluster paired bootstrap、Holm 校正和三 Seed 不确定性报告。
5. 冻结 Dev 上的交叉拟合校准、risk-coverage、亚组、state-pruning 与固定硬件 cached-feature 效率证据。
