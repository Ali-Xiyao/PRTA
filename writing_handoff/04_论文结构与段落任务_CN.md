# 论文结构与段落任务

## Abstract

- Background：纵向进展需要 current、PRIOR 与 finding 的联合建模。
- Methods：一句话描述 query、alignment、relation residual 和四项 active objective。
- Results：主结果、两个关键消融、comparator CI、cross-source、calibration。
- Conclusion：支持关键结构、性能 competitive、外部临床泛化未验证。

## Introduction

1. 定义纵向 CXR progression 与单图分类的差异。
2. 指出“双图输入”仍可能走 current shortcut。
3. 引出 finding 语义作为视觉比较查询。
4. 指出现有工作缺少结构消融、历史干预与患者级不确定性。
5. 列出五项贡献；最后一句明确冻结后验证而非持续 Dev 选模。

## Methods

按 [方法与贡献写作卡](02_方法与贡献写作卡_CN.md) 的八个小节展开。统计部分必须写明 Seeds 17/28/43、patient-cluster bootstrap 10,000 次、固定 RNG seed 20260814、Holm family 和 outcome-ranked comparison 的探索性身份。

## Results 推荐顺序

1. PRTA-CXR official Dev 三 Seed主结果。
2. Finding query 与 relation residual 两个决定性消融。
3. Alignment 和三个辅助训练项，强调效应量/CI 而非只看均值。
4. Comparator：competitive，不宣称 universal superiority。
5. Data scaling、label noise、双向 source-held。
6. PRIOR 审计协议与公开证据边界（无最终 S1 定量主表）。
7. Calibration、risk-coverage、三 Seed disagreement。
8. Subgroup、state-pruning 与 cached-feature efficiency。

## Discussion

- 第一段：关键结构结论及其与任务定义的对应关系。
- 第二段：为什么不因为 F02 或 CheXRelNet 均值更高而重选模型。
- 第三段：PRIOR 敏感性是行为证据，不是临床因果。
- 第四段：跨来源方向不对称揭示域差异。
- 第五段：校准、选择性预测和效率的部署前意义及边界。

## Limitations 必须覆盖

1. 没有独立 external clinical validation。
2. Comparator 中多项为内部重实现而非官方实现。
3. 所有主指标来自冻结 Dev，未打开 Internal-test/Gold。
4. Subgroup 样本不均，rare group 仅 277 条观察/246 名患者。
5. Cached-feature latency 不含解码、encoder、I/O。
6. 离线 referral simulation 不等于医生介入后的临床收益。
7. 没有 reader study 或医生人工部分。
