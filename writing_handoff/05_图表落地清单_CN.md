## Figure 1 绘图注意事项

- 最终图只画四个 active losses。
- 不画 standalone Prototype CE、DMW 或其他零权重历史损失。
- Tail8 标注为 adapter scope，不画成“截取 8 个 token”。
- Finding text 是 query condition，不等于直接把报告文本拼接到分类器。

## 图注统一说明

- 所有误差线注明 three-seed sample SD 或 patient-cluster 95% CI，不能混用。
- Comparator 图例标出 internal reimplementation / paper-based reimplementation。
- Source-held 图标题避免 `external validation`。
- Efficiency 图标题写 `cached-feature model forward`。
- Reliability 只连接 count_mean≥20 的 bins；联合 heatmap 灰色单元表示 suppressed，
  不表示 recall=0。
- Figure 5 只能使用 native post-softmax MHA attention；不得用 Grad-CAM 或手绘热图
  代替。所有 panel 共用一个色阶。公开仓库只含两例 aggregate maps 与 artifact hashes；
  含 MIMIC-CXR 像素的内部 PNG 在取得书面发表许可前不得提交或公开分发。
- Figure S3 的 query/seed JSD 必须使用 base-2 joint flow 与 patient-clustered 10,000 次
  bootstrap；所有定性 query 列固定同一 seed-43 pair 和同一色阶。只能写支持
  query-sensitive routing，不能写成因果或临床定位证据。
