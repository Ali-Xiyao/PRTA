| 写作任务 | 唯一首选文件 |

## 二、机器可核验结果

`evidence/` 中的 24 个同名结果文件来自 `paper/data/`，复制后逐文件
SHA256 一致。写作时优先使用本目录的人工可读总表；需要核对置信区间、
Seed 明细、配对统计或 finalizer 状态时，再进入 `evidence/`。

| 证据类别 | 主要文件 |
| --- | --- |
| 逐 Seed、bootstrap、PRIOR | `evidence/01_*`、`02_*`、`03_*` |
| 校准与选择性预测 | `evidence/05_*`、`15_*`、`16_*` |
| 效率 | `evidence/06_*` |
| Phase20-A 主结果与消融 | `evidence/12_*` |
| Comparator | `evidence/14_*` |
| Phase15 comparator 校准/亚组明细 | `evidence/phase15/` |
| B1 可信性 | `evidence/15_*` |
| B2 配对统计 | `evidence/16_*` |
| 最终完成凭据 | `evidence/17_*` |

## 三、明确不在交接包中的材料

- checkpoint、患者级预测、影像、报告、原始日志和 feature cache；
- ReXGradient 退役结果、Internal-test、Gold、医生人工数据；
- 队列、watcher、repair、finalizer、历史开发路线和服务器操作代码；
- 聊天中的中间数字或尚未进入最终聚合文件的观察。

这些边界既保护隐私，也避免写作团队将历史探索误写成最终方法证据。
