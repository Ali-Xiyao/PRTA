# 代码与复现入口

## 最终代码边界

PRTA 仓库只保留最终方法需要的模型、数据构建、缓存、训练、评估、cross-source、可信性分析、图表和测试。Phase15/16/20 队列、watcher、repair、finalizer、wave、SOL/labeling、VLM 和退役 external 代码已迁入 VisualVIT 历史归档。

GitHub `Ali-Xiyao/PRTA` 的 `main` 是唯一权威审查入口。后续代码同学只审核该
分支即可；VisualVIT 不构成最终方法依赖。

历史归档位于 VisualVIT 分支 `codex/prta-history-archive-20260822`，提交为
`fa27c71049b5a45a89816672ab4abbc44b94e547`，目录为
`_archive/PRTA-CXR-dual-branch-repair/process_code_snapshot_before_final_cleanup_20260822/`。
归档中的私有服务器账号与绝对路径已替换为通用占位符；它只用于历史审计，不能作为当前方法入口。

## 工程验证

```powershell
python -m pip install -e . --no-deps
python scripts/00_preflight.py
python scripts/06_cache_vit_tokens.py --mode preflight
python scripts/07_train.py --mode preflight
python scripts/08_evaluate.py --mode preflight
python scripts/07_train.py --mode smoke --output results/smoke/checkpoint.pt
python -m pytest
ruff check .
python -m compileall -q src scripts tests
```

Smoke 只使用合成 tensor，不打开影像、报告、患者预测或 protected outcomes。

## Checkpoint

最终 S17/S28/S43 checkpoint 为内部本地资产，不上传普通 GitHub。Git 只保存 `manifests/final_prta_cxr_checkpoints.json` 中的不可变大小与 SHA256。写作不需要 checkpoint；复现实验时由项目负责人从本地内部归档提供。
