## 图

### Figure 1：PRTA-CXR 方法图

current/prior image encoders → finding-conditioned query → cross-time alignment →
temporal relation residual → transition head。训练侧只标出 state anchor、ODC 与
matched-hard CMCP；Prototype CE 及其他零权重历史损失不应出现在最终方法图。

### Figure 2：消融 effect forest plot

使用 Phase20-B2 的患者聚类 95% CI。主图突出 w/o finding query、w/o relation
residual 与 w/o alignment；辅助模块结果使用中性色，避免把 CI 跨 0 写成确定提升。

### Figure 3：Data scaling 与 label-noise robustness

展示 10/25/50/75/100% 训练比例曲线，以及 plausible/symmetric noise 下的性能变化。
最终 S1 四条件 PRIOR 数值未进入 Git-safe 聚合，因此不安排定量 PRIOR 主图。

### Figure 4：Calibration 与 risk-coverage

绘制 uncalibrated 与 cross-fitted calibrated reliability，以及 PRTA-CXR 与主要比较器
的 risk-coverage。Reliability 使用 `data/18_*` 的真实三 Seed bins，并采用
`count_mean ≥ 20` 的绘图门；risk-coverage 继续使用 B1/B2。图注注明 referral 只是
离线选择性预测模拟。

### Figure 4b：Finding × progression heatmap

使用 `data/18_*` 的 12×5 联合 recall cells。37 个达门单元显示 mean recall，23 个
稀疏单元显示灰色破折号；不得补零或由边际亚组统计推算。

### Figure 5：Finding-conditioned temporal attention flow

两行分别展示一个 improvement-family 与一个 worsening-family 病例；每行依次为
prior CXR、prior attention-flow、current CXR、current transition relevance 和最多
6 条 strongest cross-time routes。案例严格在查看影像/attention 前按三 Seed 一致
正确、support≥100、class-conditional middle 80% confidence 和盐化哈希顺序锁定。
所有 map 共用一个 p99 clipping 色阶，不允许 panel 独立归一化。真实 attention 已
内部导出并成图；由于两例均来自受控 MIMIC-CXR-JPG，当前无单独的公开影像许可，
含 CXR 像素的 PNG 不进入公开 Git，详见
`20_Figure5_Finding-conditioned_temporal_attention_flow_CN.md`。

### Figure 6：配对对比 forest plot

展示 PRTA-CXR 相对 S0、V2、TILA8-adapted、F02-DMW0 和 outcome-ranked
CheXRelNet-inspired 的 Macro-F1/ODER 差异。CheXRelNet-inspired 使用探索性
标记，与预声明 Holm family 分开。

### Figure 7：State-pruning 与效率

报告 prediction mismatch=0、max logit difference=0，并比较 full/pruned 的固定 A800
cached-feature p50/p95、throughput、FLOPs。不得标成 raw-image end-to-end latency。

### Figure S3：Query specificity and attention stability

固定同一 prior/current pair，只更换 2 个预先锁定的 finding queries；seed 43 的
prior/current maps 使用同一 crop、插值、alpha 与 p99 色阶。全量 1,743 个可报告
multi-finding pairs 上，joint between-query JSD 为 0.577177
[0.568510,0.585631]，高于 between-seed 0.415839 [0.413229,0.418475]；CI 使用
10,000 次 patient-clustered bootstrap。内部像素图已完成，但受 MIMIC-CXR-JPG
公开再分发边界约束，不进入 public Git。详见
`21_FigureS3_Query_specificity_and_attention_stability_CN.md`。

所有需要的科学结果已经就绪；剩余工作是绘图、排版和数字交叉核对，不再需要 GPU。
