# 统计与报告协议

## 冻结原则

最终方法在 Phase20 前锁定为 PRTA-CXR（Slim-S1）。Official Dev 只用于确认；不
报告 best Seed，不根据 comparator 或 B1/B2 结果重新选模型。Internal-test、Gold、
医生人工与退役 external 数据均不进入本研究完成门。

## 终点与汇总

- 主终点：Macro-F1。
- 次要终点：Balanced Accuracy、Min Recall、ODER、NLL、Brier。
- Seeds：17、28、43；报告 mean ± sample SD。
- 推断单位：患者簇，而非逐观察独立样本。

## 患者级配对 Bootstrap

对同一冻结 Dev cohort 的系统比较使用 10,000 次 patient-cluster paired bootstrap。
最终统一定义：

`Δ = PRTA-CXR − comparator`

Macro-F1/Balanced Accuracy 的正值有利于 PRTA-CXR；ODER 的负值有利于
PRTA-CXR。所有表必须在表注中重复该方向。

## 多重比较

预声明 Holm family 包含 PRTA-CXR 对 F02-DMW0、S0、TILA8-adapted 和历史 V2
rebuild 的 Macro-F1、Balanced Accuracy、ODER，共 12 项。所有 Holm-adjusted
p 均未显示确认性差异。CheXRelNet-inspired 是按结果排序后选出的最强兼容比较器，
其检验仅为 outcome-ranked exploratory，不进入 Holm family。

## 校准与选择性预测

温度缩放按患者做五折 cross-fitting；报告校准前后 ECE、NLL、Brier、AURC，且不
把同一 Dev 上的 referral simulation 称为临床收益。Subgroup 结果为描述性分析，
不做确认性公平性或因果结论。

## 比较器命名

论文统一使用 `CheXRelNet-inspired`、`BioViL-T–style`、`TILA-adapted` 或
`paper-based adaptation`。不得使用 official implementation/checkpoint 字样。

## 数据与数字来源

最终主统计以 `data/12`、`data/14`、`data/15`、`data/16`、`data/17` 五份 Phase20
JSON 为权威来源。历史 V2 Markdown 只作开发脉络，不覆盖最终 S1 结论。
