# 效率与部署证据

## 测量合同

- 硬件：单张 NVIDIA A800 80GB PCIe；
- checkpoint：冻结 PRTA-CXR S43；
- 20 次 warm-up、100 次 CUDA Event 测量；
- 范围：预加载 cached features 后的 model forward；
- 不含磁盘 I/O、影像解码、CPU→GPU 传输与 raw-image encoder。

## PRTA-CXR full 与 state-pruned

| 状态 | 参数量 | GFLOPs/sample | Batch-1 p50 | Batch-16 throughput |
| --- | ---: | ---: | ---: | ---: |
| Full training graph | 73.307M | 74.988 | 10.698 ms | 189.16 samples/s |
| State-pruned H0 deployment | 73.307M checkpoint identity | 74.464 | 10.508 ms | 191.07 samples/s |

State pruning 不改变 checkpoint 文件，只在 H0 部署前向中跳过不参与预测的 state
token 计算。S43 的 11,201 行比较结果为 prediction mismatch=0、max absolute logit
difference=0（tolerance 1e-6）。

## 解释边界

该结果证明冻结 H0 预测路径可安全裁剪训练辅助 state 分支，并带来小幅 cached-
feature forward 改善。它不代表 raw-image 端到端临床延迟；也不能将 10.5 ms 与
包含 encoder、传输或 I/O 的其他系统数字直接比较。

权威来源：`data/15_Phase20-B1正式聚合.json`。历史 V2/Phase15 profiler 表已移至
VisualVIT 归档，不再作为 PRTA-CXR 主效率表。
