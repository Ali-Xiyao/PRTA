# 后续实验路线图（Phase16 科学协议修订版）

## 1. 冻结边界与论文主张

更新时间：2026-08-17。

- V2 主方法、33-cell 核心消融/融合矩阵、33-cell PRIOR diagnostics、患者级
  Bootstrap、Phase15 校准/效率/亚组证据继续冻结，不修改模型，也不重跑。
- F02 的平均 Macro-F1 略高于 V2，但差异区间跨 0；V2 的主要优势改写为
  **competitive Macro-F1 + 更低 ODER**，不再声称全面性能冠军。
- A01/A03 是“finding-conditioned、relation-dependent”主结构证据；A02 作为中等
  效应报告；其他训练目标消融以 effect size、CI 和 Seed consistency 为主，不声称
  每项均显著。
- 错误、缺失和反转 PRIOR 会造成明显退化，因此它们证明的是历史依赖和部署脆弱性，
  不是鲁棒性。
- 外部/跨源独立数据仍因数据合同、标签映射和严格去重而最后执行；医生人工、reader
  study 和人工伤害类型标注不做。

## 3. Phase16 自动收口

新增统一 finalizer，禁止人工从多个 retry 目录抄数。它必须：

1. 同时读取 main、retry、repair/correction shared-state roots；
2. 以修正版 87-job registry 的 scientific job ID 为唯一主键；
3. 每个预期任务只能有一个 PASS，缺失 PASS 或重复 PASS 均 fail closed；
4. 校验 state、expected output、config、checkpoint、training receipt、input hashes、
   Seed、source commit 和 protected-read flags；
5. failed/skipped/旧协议尝试仅保留在 audit，不进入均值；
6. 自动生成三 Seed mean ± SD，明确
   `selection_performed=false`、`winner_selected=false`；
7. 只有 finalizer PASS 后，Phase16 数字才能进入论文表格。

## 4. 非外部实验的执行优先级

### P0：当前双卡纠正队列

1. 修正版 modality assets 与三 Seed modality stress；
2. V2-roll exploratory source-held 重跑；
3. V1/no-CMCP confirmatory source-held 新增训练与评估；
4. state-pruning parity 与 pruned efficiency；
5. Phase16 finalizer 自动收口。

队列采用两张 A800 的 LPT 估时均衡；不打断当前不受协议修订影响的 scaling/noise
训练，待其自然结束后自动进入纠正队列。

当前已冻结 38 个受影响任务，两卡标称负载分别为 76,560 s 与 76,500 s，仅差 60 s；
等待 supervisor 与最终 finalizer 均已启动。12 个尚未开始的旧 source-held 混杂协议
任务已按 superseded 审计跳过，替代的 V2-roll exploratory 与 V1/no-CMCP
confirmatory 单元完整保留。

### P1：无需重新训练的可信融合证据

#### 4.1 PRIOR validity routing / fallback（冻结预测基础模拟已完成）

冻结 V2 和 Current-only，规则本身不学习新参数：

```text
patient identity mismatch  -> reject PRIOR
prior time >= current time -> reject PRIOR
missing PRIOR              -> current-only fallback 或 abstain
unsupported/cross view     -> warning / 预冻结策略
extreme sensitivity        -> cross-fitted threshold 下 abstain
```

固定比较：Always-V2、Invalid→Current-only、Invalid→abstain；分别在 true、null、
matched-hard wrong、reversed PRIOR 上报告 Macro-F1、ODER、coverage、error rate 和
fallback/abstention rate。阈值只能预冻结或患者级 cross-fitting，不能根据最终结果调参。

已完成的基础模拟把 synthetic intervention 身份视为已知无效标记，不拟合阈值：
Current-only fallback 在 matched-hard/null/reversed 上的 Macro-F1 均为 0.412872，
相比 Always-V2 的 0.342056/0.249746/0.191750 明显恢复；reversed ODER 从
0.171324 降至 0.035116。该结果只作为 oracle-detectable routing 上界；真实
patient/time/view validity checker 仍需独立冻结和验证。

#### 4.2 多目标 Pareto 与多重比较

- 绘制 Macro-F1–ODER–cost Pareto 图，至少包含 V2、F01、F02、Current-only；
- 同表报告 Balanced Accuracy、NLL、ECE、AURC、GFLOPs、batch-1 latency、trainable
  parameters；
- Holm families 预先划分为：主结构 A01/A02/A03、训练目标
  A04/A05/A06/A08/A10/A11、通用融合器 F01/F02；
- 同时提供把 11 项全部视为单一检验族的保守 sensitivity analysis；由于分族是在
  已有结果后固化，正文不把分族校正包装成预注册确认性检验；
- 同时保留未经调整的 effect size/95% CI 和 Holm-adjusted p，不按显著性删结果。

#### 4.3 模态压力分层

正式总表之外，按 progression class、finding、source、view relation、interval bin
分层；重点检查 New/Resolved 在 reversed PRIOR、Stable 在 null PRIOR、稀有 finding
的 prompt 敏感度和两数据源对 current corruption 的差异。

### P2：效率、grounding 与 supporting analyses

- state-pruning 必须先满足全部 predictions 一致且 `max_abs_logit_diff <= 1e-6`，再
  报告速度变化；
- 增加 raw-image endpoint latency：read/decode、preprocessing、BiomedCLIP early
  blocks、H2D、Tail8、fusion、classifier，以及 total p50/p95；缓存特征延迟继续明确
  标为 cached-representation efficiency；
- 完成 prototype geometry / grounding；
- 将 scaling curve、synthetic label-noise curve、亚组/长尾放入 supporting evidence；
  label noise 不外推为真实临床标注误差。

## 5. 真正官方方法与外部数据：最后阶段

当前三项是内部架构启发式重实现，不是 official baseline。真正官方比较单列：

1. 官方 BioViL-T；
2. 官方 CheXRelNet；
3. 官方 TILA。

只有在官方仓库/checkpoint/预处理可获得且统一五分类 head 的适配协议可审计时执行；
若官方代码缺失，可按论文复现，但必须标为 independent paper-based
reimplementation，不能再次使用 official 字样。

外部证据仍最后做：优先 CheXTemporal Gold，其次 Silver，再考虑 MS-CXR-T 或真正
独立机构数据。读取外部标签前必须冻结 checkpoint roster、finding/class mapping、
预处理、患者级严格去重、主要终点、bootstrap seed 和 excluded-row rules。

## 6. 论文材料的最终落盘顺序

1. Phase16 corrected final aggregate 与 provenance inventory；
2. 主消融/融合表：三 Seed mean ± SD、effect size、patient-cluster CI、Holm p；
3. PRIOR stress + safety routing 表；
4. F1–ODER–cost Pareto 图；
5. calibration/risk-coverage 与 state-pruning/endpoint efficiency；
6. source-held、scaling/noise、subgroup/long-tail/grounding 附表；
7. 最后加入 official/independent longitudinal comparison 与严格外部评估；
8. 全部收口后执行 `STOP_ALL_MODEL_AND_EXPERIMENT_SELECTION`。

## 7. 明确不做与不应声称

- 不修改冻结 V2，不重跑 33-cell 核心消融；
- 不因 F02 单一均值更高而重新选主方法；
- 不把内部 style/inspired 比较器写成官方实现；
- 不把错误 PRIOR 下的崩溃写成鲁棒性；
- 不把缓存 token 延迟写成原始影像端到端延迟；
- 不把 synthetic label noise 写成真实放射科标注误差；
- 不开展医生人工或 reader study；
- 不在外部合同、标签映射和严格去重冻结前启动外部评估。
