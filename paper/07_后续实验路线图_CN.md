  非外部实验全部闭环前不启动。

  复核和人工伤害类型标注移出本轮范围。

## 优先级 0：利用现有 checkpoint 补齐证据，不重新训练

### 0.1 完整校准与选择性预测（已完成）

目标输出：

- ECE、NLL、Brier；
- temperature scaling 前后对比；
- entropy、max probability、energy 等不确定性分数；
- risk-coverage curve、AURC、不同 coverage 下的 Macro-F1/错误率；
- progression-direction error 的高风险识别能力。

三 Seed 患者级五折温度缩放、ECE/AURC、coverage/referral 和 Seed disagreement
已完成；B401、TILA8、F01、F02 的同口径 true-PRIOR 概率导出与聚合也已完成。
Table 6 与 Figure 4 的比较器数据均已就绪。

### 0.2 补齐模态压力测试

已有 PRIOR：true、matched-hard、null、reversed。

待做：

- finding：zero、wrong finding、synonym/paraphrase；
- current image：强度/噪声/模糊 corruption、bbox occlusion；
- 必要时加入 prior-current misalignment。

只做冻结 checkpoint 推理，不重新训练，不从压力结果选择模型。

### 0.3 效率与部署分析（V2 与比较器已完成）

统一测量 Full V2、Current-only、TILA Tail8、F01、F02：

- total/trainable parameters；
- FLOPs 或 MACs；
- 单患者 pair latency、吞吐；
- peak GPU memory；
- checkpoint size；
- state branch 推理裁剪前后差异。

V2、Current-only、TILA Tail8、F01、F02 已在固定 A800、batch 1/16、20 warm-up、
100 repeats 下完成。剩余效率项只有 state branch pruning parity 与 raw-image
端到端延迟；混合 A800/RTX3090 wall-clock 仍不能作为公平推理效率比较。

## 最后阶段：外部证据（因数据问题明确后置）

### 1.1 严格外部/跨源评估

推荐顺序：

1. CheXTemporal Gold：完整标签兼容性、严格 overlap/de-dup receipt、患者级 CI；
2. CheXTemporal Silver：大规模 source-stratified robustness，只作次级证据；
3. MS-CXR-T 或真正独立机构数据：只在标签映射和授权明确后运行。

外部 preparation receipt 必须冻结 checkpoint roster、finding/class mapping、图像
预处理、去重算法、主要终点、bootstrap seed 和 excluded-row rules，然后才允许
读取一次标签并聚合。

### 1.2 官方纵向方法

至少补：official TILA、BioViL-T、CheXRelNet，各 3 Seeds。必须使用官方实现/权重、
统一 cleaned split、同标签映射和同评估器。不要把当前的 TILA-style comparator
写成 official TILA。
