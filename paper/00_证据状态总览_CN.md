## 冻结决策

1. Full V2 保持为论文主方法，不用 Dev 结果重新选择 F02。
2. 不报告 best seed；固定使用 17、28、43。
3. 所有主张以三 Seed 汇总和患者级 paired bootstrap 为准。
4. 消融表强调 effect size 与 CI；除预先定义的主比较外不扩张显著性主张。
5. controlled intervention 只说明模型行为和机制敏感性，不等于临床因果证明。
6. Slim-S1 是 Train-only 冻结规则下的精简候选；Full V2 和历史消融证据不删除、
   不覆盖，外部验证前不把 Slim-S1 称为临床最终模型。
