## 2. 推荐的第二优势：分支分歧驱动的不确定性与病例转交

双分支的更合适附加价值不是继续堆叠分类模块，而是利用 transition 基础判断
与 state-conditioned 修正之间的分歧，生成可审计的不确定性信号：

- 两个判断接近：模型对时序结论更一致；
- 修正幅度或分歧较大：样本更可能困难，应进入人工复核/转交队列；
- 每个预测可拆成基础 transition logits、门控强度和联合修正 logits，便于解释
  双分支究竟是在纠错还是引入新错误。

首选诊断分数为：

`uncertainty = gate * JS(softmax(base_logits), softmax(final_logits))`

并同时报告无需概率假设的备选分数：

`correction_magnitude = gate * ||residual_logits||₂`

这些量仅作为冻结 checkpoint 的评估诊断，不参与重新训练或选择测试结果。

## 3. Train/Dev-only 验证项目

使用现有三个冻结 H4 checkpoint，先进行无训练的只读分析：

1. **错误识别**：用分支分歧判断最终预测是否错误，报告 AUROC、AUPRC；
2. **选择性预测**：转交最高风险的 5%、10%、20% 样本，报告剩余覆盖率下的
   Macro-F1、错误率和 AURC；
3. **基线比较**：与最大 softmax 概率、预测熵比较，证明分支分歧是否提供额外
   风险信息；
4. **修正审计**：报告 transition-only 错误被 H4 修正的数量、H4 新引入错误的
   数量、净修正率；
5. **分层分析**：分别报告 NoChange 与 Changed，以及五个进展标签上的门控、
   分歧和转交效果；
6. **时序反事实一致性（探索性）**：在不访问受保护数据的前提下，检查交换
   prior/current 后 Improved/Worse、New/Resolved 的映射一致性。

## 4. 预设成功规则

只有同时满足以下条件，论文才可把可靠性写成双分支的第二优势：

- 分支分歧的 AURC 优于普通 softmax entropy，且至少 2/3 seed 方向一致；
- 转交最高风险 10% 样本后，剩余样本错误率下降，且覆盖率计算完整；
- 净修正率为正，不能只展示成功案例；
- 所有 seed、所有阈值和失败结果均完整报告；
- 全过程只使用冻结 Train/Dev，不读取 Internal-test 或 Gold。

若这些条件不成立，论文只保留“小幅 Macro-F1 增益与可分解结构”结论，不得
宣称更好的不确定性、临床安全性或人工转交价值。

## 5. 后续可选校准

只有无训练分析首先证明分支分歧具有增量信息，才允许增加一个轻量的置信度
校准层。校准层必须使用 Train 内部拟合、Dev 一次验证，并与原始 entropy
基线比较；不得进行无上限调参，也不得重新打开 Internal-test/Gold。
