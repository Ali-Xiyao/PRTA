# PRTA-CXR Gold 资深医生 Luna 辅助复核说明

版本：v2.0

日期：2026-08-02

适用范围：冻结的 250 条 Gold 候选

## 1. 本轮目的

本轮由资深医生复核 Luna 对目标病灶纵向变化给出的标签。工作簿会显示
`Luna标签`，因此本轮属于 **Luna 辅助复核**，不是独立盲审。

第一位医生的填写结果已经从项目工作簿和运行时审计目录中清除，本轮工作簿不包含
第一位医生的任何答案、备注或身份信息。

## 2. 填写方式

每行只判断指定的 `finding`，依据 `PRIOR_REPORT` 和 `CURRENT_REPORT`：

1. 查看 Luna 给出的 `Luna标签`；
2. 在 `资深医生标签` 中填写您认为正确的最终标签；
3. 可选标签为 `Improved / Worse / New / Resolved / Stable / Unclear / Unusable`；
4. 若选择 `Unusable`，必须填写 `不可用原因`；
5. 若修改 Luna 标签，建议在 `备注（可选）` 中简要说明关键边界；
6. 填写 `审核人` 和 `审核日期`；
7. 不要修改 `review_id`、Luna 标签、报告正文或其他只读列。

五类标签及 `Unclear`、`Unusable` 的详细医学边界见同一压缩包内的
`PRTA_CXR_Gold标签判定规则_v2_CN.md`。

## 3. 完成门禁

回收工作簿前应满足：

- 250 行均填写 `资深医生标签`、`审核人` 和 `审核日期`；
- 所有 `Unusable` 行均填写 `不可用原因`；
- `review_id` 未修改、删除或重复；
- “质量检查”页显示未完成行数为 0。

资深医生完成复核后，项目程序将按 `review_id` 对照 Luna 标签，报告确认率、修正率、
各来源和各类别结果，并冻结资深医生五分类标签作为 Gold 候选。`Unclear` 和
`Unusable` 不进入 Gold，所有 250 名患者继续与训练数据隔离。

本轮完成不自动授权训练；Gold 冻结、patient-disjoint 审计和正式训练仍需单独确认。
