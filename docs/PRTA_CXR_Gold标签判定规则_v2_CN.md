# PRTA-CXR Gold 标签判定规则

版本：v2.0

日期：2026-08-02

适用范围：资深医生 Luna 辅助复核表中的 250 条冻结样本

## 1. 审核单位

每行只判断指定 `finding` 在 `PRIOR_REPORT`（较早）与
`CURRENT_REPORT`（较晚）之间的变化。报告中的其他病灶不影响本行标签。

`Luna标签` 是待核对的参考结果。资深医生应结合两份报告给出自己的最终标签；若不认可
Luna 标签，直接在 `资深医生标签` 中选择正确类别即可。

## 2. 允许标签

### `Improved`

PRIOR 中病灶存在，CURRENT 中仍存在，但程度、范围、数量或严重性明确减轻。完全消失
应标为 `Resolved`。

### `Worse`

PRIOR 中病灶存在，CURRENT 中程度、范围、数量或严重性明确增加。新出现的病灶应标为
`New`。

### `New`

PRIOR 中目标病灶明确不存在，CURRENT 中明确新出现。PRIOR 仅仅未提及该病灶，不能
自动视为明确阴性；证据不足时应标为 `Unclear`。

### `Resolved`

PRIOR 中病灶存在，CURRENT 中明确消失、完全缓解或不再可见。CURRENT 仅未提及不能
自动视为消失；证据不足时应标为 `Unclear`。

### `Stable`

前后两次目标病灶均存在，且明确无实质变化。两次均明确阴性不属于 `Stable`，应标为
`Unusable`。

### `Unclear`

报告和配对可读，但现有文字不足以可靠区分五类。包括：

- PRIOR 未提及、CURRENT 提及，但无法确认是否新发；
- PRIOR 提及、CURRENT 未提及，但无法确认是否消失；
- “可能、疑似、不能排除”等表达导致存在状态不确定；
- 报告内部矛盾或前后变化方向不明确；
- 无法可靠区分 `Improved/Resolved`、`New/Worse` 或 `Stable/其他类别`。

### `Unusable`

样本结构或内容不适合纵向判断，且必须填写 `不可用原因`。包括报告缺失、错配、损坏、
目标病灶无关、前后不可比较、重复样本或两次均明确阴性等。

## 3. 推荐判定顺序

1. 确认两份报告完整可读且前后方向正确；
2. 只定位指定 `finding`；
3. 分别判断 PRIOR 和 CURRENT 中病灶为存在、不存在或不确定；
4. 证据充分时选择五类之一；
5. 报告可用但方向不足时选 `Unclear`；
6. 结构或内容不合格时选 `Unusable` 并填写原因；
7. 最后核对 Luna 标签；若不同，以资深医生判断为准，建议在备注中说明边界。

## 4. 边界速查

| PRIOR | CURRENT | 标签 |
|---|---|---|
| 病灶存在 | 减轻但仍存在 | `Improved` |
| 病灶存在 | 明确消失 | `Resolved` |
| 明确不存在 | 明确新出现 | `New` |
| 病灶存在 | 明确加重 | `Worse` |
| 病灶存在 | 明确无变化 | `Stable` |
| 未提及 | 提及但无新发证据 | `Unclear` |
| 提及 | 未提及但无消失证据 | `Unclear` |
| 两次均明确阴性 | 两次均明确阴性 | `Unusable` |
| 缺失、错配、损坏或不可比较 | 任意 | `Unusable` |

不要用患者年龄、其他病灶、治疗预期或常识推测补足报告中没有的信息。本规则仅用于科研
数据质量审核，不能替代临床诊断或患者照护决策。
